A stdlib-only Python program for the [Make the AI Judge Laugh: Cat Reviews Its Human](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990) bounty on make.fun.

`main.py` writes one funny single-line one-star review from a house cat about its human (131 characters) to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`).

Run it:

```sh
python3 main.py
```
